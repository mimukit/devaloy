# The WITH_BROWSER apt list: what a headless Chromium needs to start on a
# minimal noble base, plus ffmpeg. Same format as packages.txt: one package per
# line, `#` comments, blank lines skipped. Installed only when WITH_BROWSER=true,
# by the Dockerfile's browser block and by the native installer.
#
# The library set is what `playwright install-deps chromium` resolves on noble,
# listed by hand so a build never runs an installer script as root. The browser
# itself is not here: bootstrap-toolchain.sh downloads Playwright's Chromium
# into ~/.cache/ms-playwright.
libnss3
libnspr4
libatk1.0-0t64
libatk-bridge2.0-0t64
libcups2t64
libdrm2
libxkbcommon0
libxcomposite1
libxdamage1
libxfixes3
libxrandr2
libgbm1
libpango-1.0-0
libcairo2
libasound2t64
# For GIF conversion. Playwright ships its own ffmpeg build for video
# recording, but that build only records, and a webm from `video-stop`
# needs a real ffmpeg to become a GIF.
ffmpeg
